// Hvad er ByteForge?
EN SERVER
DU EJER

ByteForge er et selvhostet homelab system bygget på en privatpersons computer. Tænk på det som dit eget private cloud – men uden månedlige abonnementer, uden at sende dine data til fremmede servere, og uden begrænsninger.

Systemet kører på Manjaro Linux med CasaOS som fundament, og er udvidet med NAS-deling, RAID-beskyttelse, en Minecraft-server og et komplet kontrolpanel bygget fra bunden.

Alt er tilgængeligt via din browser – fra hvilken som helst enhed på netværket. Ingen app-downloads, ingen cloud-login. Bare din server.

1
DOWNLOAD OG UDPAK
Download ByteForge.zip via knappen ovenfor. Udpak ZIP-filen til en mappe på din computer eller server. Du kan placere den hvor du vil – f.eks. i din hjemmemappe.
unzip ByteForge.zip && cd ByteForge/ByteForge

Åbn en terminal i ByteForge-mappen og kør Python-serveren. Du behøver ikke installere noget ekstra – Python 3 er nok til at komme i gang.
python3 byteforge-server.py

ÅBEN I BROWSER
Når serveren kører åbner du din browser og går til denne adresse. Panelet starter med det samme – ingen login nødvendig ved første start.
http://localhost:8080
4
TILSLUT NAS-DREVET (VALGFRIT)
Del filer på tværs af alle enheder. NAS-mappen er tilgængelig for alle enheder på netværket. Windows bruger Stifinder, Mac bruger Finder → Cmd+K.
Windows: \\10.194.177.172\nas-share
Mac: nfs://10.194.177.172/mnt/nas-share
Linux: mount -t nfs 10.194.177.172:/mnt/nas-share /mnt/remote
5
JOIN MINECRAFT SERVEREN
Åbn Minecraft → Multiplayer → Tilføj server. Brug IP-adressen nedenfor. Serveren kører PaperMC og starter automatisk ved genstart.
10.194.177.172:25565
6
PORT FORWARD TIL INTERNET
Log ind på din router og forward portene til serverens IP-adresse. Så kan du tilgå alt udefra via din offentlige IP-adresse.
Router IP: find med kommandoen: ip route | grep default | awk '{print $3}'
Din offentlige IP: curl ifconfig.me

01
// Installation
KOM I GANG PÅ 3 MINUTTER

ByteForge kræver ingen kompleks opsætning. Du behøver kun Python 3 – som allerede er installeret på de fleste Linux-systemer og Mac. Følg disse trin præcist.

  1. → 1
    DOWNLOAD OG UDPAK ZIP-FILEN
    Klik på "Download ByteForge" knappen øverst på siden. Filen hedder ByteForge.zip og fylder ca. 1 MB. Gem den et sted du kan finde den – f.eks. Skrivebord eller Downloads.
    # I terminal – udpak filen unzip ByteForge.zip # Gå ind i mappen cd ByteForge/ByteForge
    💡
    På Windows: Højreklik på ZIP-filen → "Udpak alt" → Åbn mappen der dukker op, og gå ind i den indre "ByteForge" mappe.
  2. → 2
    TJEK AT PYTHON 3 ER INSTALLERET
    Åbn en terminal (på Windows: søg efter "cmd" eller "PowerShell") og kør denne kommando. Du skal se noget som "Python 3.10.x" – så er du klar.
    python3 --version # Forventet output: Python 3.10.x eller nyere
    ⚠
    Har du ikke Python 3? Hent det gratis fra python.org – vælg den nyeste version og sæt flueben ved "Add to PATH" under installation.
  3. → 3
    START BYTEFORGE-SERVEREN
    Sørg for at din terminal er i ByteForge-mappen (cd ByteForge/ByteForge) og kør denne kommando. Lad terminalen stå åben – den skal køre så længe du bruger ByteForge.
    python3 byteforge-server.py # Du ser dette når den er klar: # [OK] ByteForge kørende på http://localhost:8080
  4. → 4
    ÅBEN PANELET I DIN BROWSER
    Åbn Chrome, Firefox eller Edge og skriv denne adresse i adressefeltet. Tryk Enter. ByteForge-panelet åbner med det samme.
    http://localhost:8080
    💡
    Kører ByteForge på en anden computer på dit netværk? Brug computerens lokale IP-adresse i stedet for "localhost" – f.eks. http://10.194.177.172:8080
  5. → 5
    SKIFT PORT ELLER DATA-MAPPE (VALGFRIT)
    Vil du bruge en anden port eller gemme data et andet sted, kan du sætte environment-variabler før du starter. Data gemmes som standard i ~/.byteforge (eller /opt/byteforge som root).
    BYTEFORGE_HOME="/din/mappe" BYTEFORGE_PORT=9000 python3 byteforge-server.py
🔴
Stop ikke terminalen! Terminalen hvor byteforge-server.py kører skal forblive åben. Lukker du den, stopper panelet. Vil du køre det permanent i baggrunden, se "Kør som service" i FAQ.

// Game Server Management
OPRET OG ADMINISTRER GAME SERVERS

ByteForge understøtter otte forskellige servertyper. Alle kører via Docker, som håndterer alt det tekniske automatisk. Du behøver ikke forstå Docker – ByteForge gør det for dig.

⛏
MINECRAFT VANILLA
Standard Minecraft-server. Perfekt til normale spil uden mods. Port: 25565
📄
MINECRAFT PAPER
Optimeret server med plugin-understøttelse. Bedre performance end Vanilla. Anbefalet til de fleste
🔌
SPIGOT / FORGE / FABRIC
Avancerede servertyper til mods og plugins. Vælg efter hvad dine spillere bruger.
🚗
FIVEM
GTA V multiplayer-server. Kræver FiveM-licens fra cfx.re. Custom scripts understøttet
🌳
TERRARIA
Terraria dedikeret server. Understøtter op til 255 spillere. Ingen mods påkrævet
⚙
CUSTOM SERVER
Kør en hvilken som helst spilserver via Docker-image. Du angiver selv image og konfiguration.

  1. → 1
    OPRET EN NY SERVER
    Åbn ByteForge-panelet → Klik på "Game Servers" i venstremenuen → Klik på den store orange knap "+ NY SERVER". En formular åbner sig.
  2. → 2
    UDFYLD SERVER-INFORMATIONER
    Giv serveren et navn (f.eks. "Lucas Survival"), vælg servertype fra dropdown-menuen, og indstil RAM-grænse (anbefalet: 2048 MB til Minecraft). CPU-grænse kan efterlades på standard.
    💡
    Start med 2GB RAM til Minecraft. Har du mange spillere eller mods, kan du øge det til 4GB bagefter via "Rediger server".
  3. → 3
    START, STOP OG GENSTART
    I serverlisten har hver server tre knapper: ▶ Start, ■ Stop og ↺ Genstart. Klik blot på den du vil bruge. Status-indikatoren bliver grøn når serveren kører.
  4. → 4
    AUTO-RESTART VED SERVERFEJL
    Alle servere er konfigureret med unless-stopped – det betyder at Docker automatisk genstarter serveren hvis den crasher, men stopper den hvis du manuelt trykker Stop. Ingen ekstra opsætning nødvendig.
  5. → 5
    TILSLUT TIL DIN SERVER
    Åbn Minecraft → Multiplayer → Tilføj server. Skriv serverens IP og port i feltet. Brug lokal IP på hjemmenetværk, offentlig IP udefra.
    # Lokalt (hjemmenetværk): 10.194.177.172:25565 # Udefra (efter port forwarding): [DIN OFFENTLIGE IP]:25565
03
// Filhåndtering
FIL MANAGER OG STORAGE

ByteForge har en komplet filhåndtering direkte i browseren. Du kan uploade, slette, flytte og søge i filer uden at have adgang til terminalen. Filsystemet er inddelt i fire zoner.

PUBLIC
// tilgængeligt uden login
Filer her er tilgængelige for alle via HTTP. Brug til hjemmesider, delte billeder, offentlige downloads og video/PDF-filer du vil dele med andre.
PRIVATE
// kun din profil
Dine personlige filer. Kun din bruger kan se og redigere disse filer. Andre brugere på systemet har ikke adgang.
SHARED
// alle loggede brugere
Filer som alle brugere på systemet kan se og redigere. Perfekt til fælles projekter og delte ressourcer internt.
SERVER DATA
// pr. game server
Hver game server har sin egen mappe til konfigurationsfiler, worlds, mods og plugins. Tilgås via den pågældende servers "Filer"-faneblad.

  1. → 1
    UPLOAD EN FIL
    Gå til Filer i menuen → Vælg din storage-zone (Public, Private eller Shared) → Klik på "Upload" knappen → Vælg filen fra din computer. Filen uploades øjeblikkeligt.
    💡
    Du kan uploade flere filer på én gang ved at holde Ctrl nede mens du vælger dem i filvinduet.
  2. → 2
    OPRET EN MAPPE
    I Fil Manager klik på "Ny mappe" ikonet (mappesymbol med + tegn) øverst i panelet. Skriv mappenavnet og tryk Enter. Mapper kan indeholde andre mapper – der er ingen grænse på dybden.
  3. → 3
    FLYT EN FIL
    Højreklik på filen → Vælg "Flyt" → Naviger til destinationsmappen → Klik "Flyt hertil". Du kan også flytte hele mapper på samme måde.
  4. → 4
    SØG EFTER FILER
    Øverst i Fil Manager er der et søgefelt. Skriv noget af filnavnet og resultater filtreres øjeblikkeligt. Søgningen finder filer i alle undermapper automatisk.
  5. → 5
    SLET EN FIL ELLER MAPPE
    Højreklik på filen eller mappen → Vælg "Slet" → Bekræft i den dialog der dukker op. Bemærk: Sletning kan ikke fortrydes! Tjek altid at du sletter den rigtige fil.
    ⚠
    Sletning er permanent. Der er ingen papirkurv. Overvej at flytte vigtige filer til PRIVATE zonen som backup inden du sletter fra SHARED.
04
// Brugerstyring
MULTI-USER PROFILER

ByteForge understøtter flere brugere med individuelle adgangsniveauer. Perfekt til at give venner eller familiemedlemmer adgang til specifikke dele af systemet – uden at de kan rode med alt.

  1. → 1
    OPRET EN NY BRUGER
    Åbn panelet → Klik på "Brugere" i menuen → Klik "+ Ny bruger" → Udfyld brugernavn og adgangskode → Vælg adgangsniveau → Klik "Gem".
  2. → 2
    ADGANGSNIVEAUER FORKLARET
    Admin — Fuld adgang til alt inkl. brugeroprettelse og sletning af servere.
    Bruger — Kan starte/stoppe servere og uploade filer. Kan ikke slette eller ændre konfiguration.
    Gæst — Kan kun se status. Ingen ændringer tilladt.
  3. → 3
    SKIFT ELLER SLET BRUGER
    I brugerlisten klik på blyantsikonet ud for en bruger for at redigere adgangsniveau eller skifte adgangskode. Klik på skraldespandsikonet for at slette brugeren permanent.
    💡
    Du kan ikke slette din egen admin-konto. Opret altid mindst én ekstra admin som backup i tilfælde af at du glemmer din adgangskode.
05
// Web Hosting
HOST DIN EGEN HJEMMESIDE

ByteForge kan hoste statiske hjemmesider direkte fra PUBLIC storage-zonen. Upload dine HTML/CSS/JS-filer og de er øjeblikkeligt tilgængelige via HTTP – ingen ekstra webserver nødvendig.

  1. → 1
    UPLOAD DIN HJEMMESIDE
    Gå til Filer → Public → Upload din index.html fil (og eventuelle CSS/JS-filer). Organiser dem i mapper hvis du vil.
    # Din hjemmeside er nu tilgængeligt på: http://[SERVER-IP]:8080/public/index.html
  2. → 2
    SHARE VIDEOER OG FILER
    Upload videofiler, PDF'er eller andre filer til PUBLIC og del linket. Enhver med adgang til din server kan hente filen via det direkte link uden at logge ind.
    http://[SERVER-IP]:8080/public/min-video.mp4 http://[SERVER-IP]:8080/public/dokument.pdf
  3. → 3
    GØR DET TILGÆNGELIGT FRA INTERNET
    Vil du dele din hjemmeside med verden? Forward port 8080 i din router til serverens lokale IP-adresse. Derefter er siden tilgængeligt på din offentlige IP.
    💡
    Brug en gratis DNS-tjeneste som DuckDNS eller No-IP for at få et domænenavn i stedet for en IP-adresse – f.eks. minserver.duckdns.org

ByteForge kan tilpasses med temaer, sprog og brugerdefineret baggrund direkte fra panelet – ingen koderedigering nødvendig.

  1. → 1
    SKIFT TEMA
    Gå til Indstillinger (tandhjulsikon) → "Udseende" → Vælg et tema fra listen. Standardtemaet er det orange ByteForge-tema. Du kan skifte til mørkere eller lysere varianter.
  2. → 2
    SKIFT SPROG
    Gå til Indstillinger → "Sprog" → Vælg dit foretrukne sprog fra dropdown-menuen. Panelet genindlæser automatisk med det valgte sprog.
  3. → 3
    TILPASSET BAGGRUND
    Gå til Indstillinger → "Baggrund" → Klik "Upload billede" eller indsæt en URL til et billede. ByteForge bruger billedet som baggrund i hele panelet.
  4. → 4
    API-NØGLER OG INTEGRATIONER
    Under Indstillinger → "Integrationer" kan du tilføje din Claude API-nøgle til AI-assistenten, Discord webhook til notifikationer og andre tredjepartstjenester.
    # API endpoint oversigt: GET /api/all → Alt systemdata GET /api/game-servers → Liste over servere POST /api/game-servers/create → Opret server POST /api/game-servers/action → Start/stop/restart GET /api/files?scope=public → Filer i public POST /api/files/upload → Upload fil POST /api/settings → Gem indstillinger

FAQ
Hvad koster det at drive ByteForge?
ByteForge kører på din egen hardware – der er ingen månedlige abonnementer eller cloud-gebyrer. Du betaler kun for den strøm serveren bruger, typisk 15-30W for en moderne mini-PC. Det svarer til ca. 100-200 kr. om måneden i strøm.
Skal jeg have teknisk erfaring for at bruge det?
ByteForge panelet er designet til at være brugervenligt. De fleste funktioner kræver kun klik i browseren. Terminal-kommandoer er kun nødvendige ved den første opsætning, og guiden her forklarer præcist hvad du skal gøre.
Er mine data sikre?
Ja – fordi alt kører på din egen hardware i dit eget netværk. Dine filer forlader aldrig din server medmindre du aktivt sender dem videre. Med RAID 1 er dine data desuden beskyttet mod diskfejl.
Hvad sker der hvis strømmen går?
Alle services er konfigureret til at starte automatisk når serveren genstarter. Docker-containere, ByteForge panelet, NFS-serveren og Minecraft starter alle op af sig selv via systemd.
Kan jeg tilgå serveren udefra hjemmenet?
Ja – ved at port-forwarde portene i din router (se Port-oversigten ovenfor). Derefter kan du bruge din offentlige IP-adresse til at tilgå ByteForge fra hvor som helst i verden. For ekstra sikkerhed anbefales WireGuard VPN.
Kan jeg tilføje flere apps?
Absolut. Via CasaOS App Store kan du installere hundredevis af apps med ét klik – Jellyfin, Nextcloud, Grafana, Bitwarden og mange flere. Via ByteForge panelet kan du deploye komplette Docker-stacks med presets.
Hvordan kører jeg ByteForge permanent i baggrunden?
Opret en systemd service-fil så ByteForge starter automatisk med systemet. Kør: sudo nano /etc/systemd/system/byteforge.service — skriv service-konfigurationen og kør: sudo systemctl enable byteforge && sudo systemctl start byteforge. Herefter starter ByteForge automatisk ved genstart.
Virker ByteForge på Windows?
Ja – men med begrænsninger. Python-serveren kører fint på Windows. Game servers via Docker kræver Docker Desktop for Windows. For den bedste oplevelse anbefales Linux (Manjaro, Ubuntu eller lignende) eller WSL2 på Windows.
