ByteForge – Custom CasaOS Theme
Et moderne, mørkt og futuristisk tema til CasaOS, designet til at give dit dashboard et skarpt, teknisk og stilrent udtryk. ByteForge erstatter standard‑UI’et med en gennemført farvepalette, skarpe kanter, neon‑orange highlights og en subtil hex‑grid baggrund.

Perfekt til dig, der vil give din server et unikt look.

Features
- Komplet redesign af CasaOS UI  
- Mørkt tema med orange neon‑accent  
- Hex‑grid baggrund (lav CPU‑belastning)  
- Custom typografi (Bebas Neue, Rajdhani, DM Mono)  
- Flade knapper og paneler uden afrundede hjørner  
- Hover‑effekter og glows  
- Tilpassede:
  - Cards  
  - Modals  
  - Tabs  
  - Inputs  
  - Dropdowns  
  - Sliders  
  - Switches  
  - Tables  
  - Notifications  
- Fuldt kompatibelt med CasaOS 0.4+  

Installation

1. Download byteforge-custom.css
Hent filen fra Releases eller fra repoet.

2. Upload til CasaOS
Placer filen her:

`
/var/lib/casaos/www/css/custom.css
`

Hvis filen allerede findes, så erstat den.

3. Genstart CasaOS UI
Du kan enten:

- genindlæse browseren  
- eller genstarte CasaOS via terminal:
`
sudo systemctl restart casaos
`
4. Færdig!
Dit nye ByteForge‑tema er nu aktivt.

Systemkrav
- CasaOS 0.4 eller nyere  
- Browser med CSS‑support (Chrome, Edge, Firefox, Safari)  

Hvorfor ByteForge?
CasaOS mangler gode themes — ByteForge giver dig:

- Et unikt look  
- En professionel UI‑stil  
- Et dashboard der føles som et rigtigt OS  
- Et brand du kan bygge videre på
