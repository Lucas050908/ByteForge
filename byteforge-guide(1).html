// Hvad er ByteForge?
EN SERVER
DU EJER

ByteForge er et selvhostet homelab system bygget på en privatpersons computer. Tænk på det som dit eget private cloud – men uden månedlige abonnementer, uden at sende dine data til fremmede servere, og uden begrænsninger.

Systemet kører som et standalone system på Manjaro Linux, udvidet med NAS-deling, RAID-beskyttelse, game servers og et komplet kontrolpanel bygget fra bunden.

Alt er tilgængeligt via din browser – fra hvilken som helst enhed på netværket. Ingen app-downloads, ingen cloud-login. Bare din server.

byteforge-server.py

SÅDAN
STARTER DU

Alt kører automatisk. Her er en oversigt over hvad der sker bag kulisserne, og hvordan du tilgår de forskellige dele af systemet.

1
DOWNLOAD OG UDPAK
Download ByteForge.zip via knappen ovenfor. Udpak ZIP-filen til en mappe på din computer eller server. Installerne skal køres fra den yderste ByteForge-mappe.
unzip ByteForge.zip && cd ByteForge
2
KØR TERMINAL-INSTALLEREN
Installeren spørger efter et ADMIN password, kopierer filerne, tilbyder Docker-installation og opsætter ByteForge som system-service hvor operativsystemet understøtter det.
Linux: sudo ./install.sh macOS: ./install.sh Windows: .\install.ps1
3
LOG IND SOM ADMIN
Når serveren kører åbner du din browser og logger ind med brugernavnet ADMIN og det password du valgte i terminalen.
http://127.0.0.1:8080 Username: ADMIN
4
TILSLUT NAS-DREVET (VALGFRIT)
Del filer på tværs af alle enheder. NAS-mappen er tilgængelig for alle enheder på netværket. Windows bruger Stifinder, Mac bruger Finder → Cmd+K.
Windows: \\10.194.177.172\nas-share
Mac: nfs://10.194.177.172/mnt/nas-share
Linux: mount -t nfs 10.194.177.172:/mnt/nas-share /mnt/remote
5
JOIN MINECRAFT SERVEREN
Åbn Minecraft → Multiplayer → Tilføj server. Brug IP-adressen nedenfor. Serveren kører PaperMC og starter automatisk ved genstart.
10.194.177.172:25565
6
PORT FORWARD TIL INTERNET
Log ind på din router og forward portene til serverens IP-adresse. Så kan du tilgå alt udefra via din offentlige IP-adresse.
Router IP: find med kommandoen: ip route | grep default | awk '{print $3}'
Din offentlige IP: curl ifconfig.me

01
// Installation
KOM I GANG PÅ 3 MINUTTER

ByteForge installeres fra terminalen på Linux, macOS og Windows. Installeren vælger ADMIN password, opsætter service og håndterer Docker som en system-opgave i stedet for at forsøge at hæve rettigheder fra browseren.

  1. → 1
    DOWNLOAD OG UDPAK ZIP-FILEN
    Klik på "Download ByteForge" knappen øverst på siden. Filen hedder ByteForge.zip. Gem den et sted du kan finde den – f.eks. Skrivebord eller Downloads.
    # I terminal – udpak filen unzip ByteForge.zip # Gå ind i projektmappen cd ByteForge
    💡
    På Windows: Højreklik på ZIP-filen → "Udpak alt" → Åbn mappen der dukker op. Kør install.ps1 fra den yderste ByteForge-mappe.
  2. → 2
    KØR INSTALLEREN I TERMINALEN
    Vælg kommandoen for dit operativsystem. Installeren spørger efter ADMIN password og tilbyder at installere Docker, fordi Docker-installation kræver systemrettigheder.
    # Linux sudo ./install.sh # macOS ./install.sh # Windows PowerShell .\install.ps1
    ⚠
    Har du ikke Python 3? Installeren stopper og fortæller det. På Windows skal Python være i PATH.
  3. → 3
    ÅBEN BYTEFORGE
    Når installationen er færdig, starter ByteForge som service. Åbn browseren og brug ADMIN som brugernavn.
    http://127.0.0.1:8080 Username: ADMIN Password: det du valgte i terminalen
  4. → 4
    MANUEL START (VALGFRIT)
    Vil du teste uden service, kan du starte backend manuelt. Første login-skærm lader dig vælge ADMIN password hvis det ikke allerede findes.
    cd ByteForge/ByteForge python3 byteforge-server.py
    💡
    Kører ByteForge på en anden computer på dit netværk? Brug computerens lokale IP-adresse i stedet for "localhost" – f.eks. http://10.194.177.172:8080
  5. → 5
    SKIFT PORT ELLER DATA-MAPPE (VALGFRIT)
    Vil du bruge en anden port eller gemme data et andet sted, kan du sætte environment-variabler før du starter. Data gemmes som standard i ~/.byteforge (eller /opt/byteforge som root).
    BYTEFORGE_HOME="/din/mappe" BYTEFORGE_PORT=9000 python3 byteforge-server.py
🔴
Docker skal installeres fra terminalen. Browseren kan ikke hæve rettigheder til root/admin. Derfor spørger ByteForge-installeren om Docker under setup, ligesom CasaOS gør.
02
// Game Server Management
OPRET OG ADMINISTRER GAME SERVERS

ByteForge understøtter otte forskellige servertyper. Alle kører via Docker, som håndterer alt det tekniske automatisk. Du behøver ikke forstå Docker – ByteForge gør det for dig.

⛏
MINECRAFT VANILLA
Standard Minecraft-server. Perfekt til normale spil uden mods. Port: 25565
📄
MINECRAFT PAPER
Optimeret server med plugin-understøttelse. Bedre performance end Vanilla. Anbefalet til de fleste
🔌
SPIGOT / FORGE / FABRIC
Avancerede servertyper til mods og plugins. Vælg efter hvad dine spillere bruger.
🚗
FIVEM
GTA V multiplayer-server. Kræver FiveM-licens fra cfx.re. Custom scripts understøttet
🌳
TERRARIA
Terraria dedikeret server. Understøtter op til 255 spillere. Ingen mods påkrævet
⚙
CUSTOM SERVER
Kør en hvilken som helst spilserver via Docker-image. Du angiver selv image og konfiguration.

  1. → 1
    OPRET EN NY SERVER
    Åbn ByteForge-panelet → Klik på "Game Servers" i venstremenuen → Klik på den store orange knap "+ NY SERVER". En formular åbner sig.
  2. → 2
    UDFYLD SERVER-INFORMATIONER
    Giv serveren et navn (f.eks. "Admin Survival"), vælg servertype fra dropdown-menuen, og indstil RAM-grænse (anbefalet: 2048 MB til Minecraft). CPU-grænse kan efterlades på standard.
    💡
    Start med 2GB RAM til Minecraft. Har du mange spillere eller mods, kan du øge det til 4GB bagefter via "Rediger server".
  3. → 3
    START, STOP OG GENSTART
    I serverlisten har hver server tre knapper: ▶ Start, ■ Stop og ↺ Genstart. Klik blot på den du vil bruge. Status-indikatoren bliver grøn når serveren kører.
  4. → 4
    TILSLUT TIL DIN SERVER
    Åbn Minecraft → Multiplayer → Tilføj server. Skriv serverens IP og port i feltet. Brug lokal IP på hjemmenetværk, offentlig IP udefra.
    # Lokalt (hjemmenetværk): 10.194.177.172:25565 # Udefra (efter port forwarding): [DIN OFFENTLIGE IP]:25565
03
// Filhåndtering
FIL MANAGER OG STORAGE

ByteForge har en komplet filhåndtering direkte i browseren. Filsystemet er inddelt i fire zoner.

PUBLIC
// tilgængeligt uden login
Filer her er tilgængelige for alle via HTTP. Brug til hjemmesider, delte billeder og offentlige downloads.
PRIVATE
// kun din profil
Dine personlige filer. Kun din bruger kan se og redigere disse filer.
SHARED
// alle loggede brugere
Filer som alle brugere på systemet kan se og redigere. Til fælles projekter.
SERVER DATA
// pr. game server
Hver game server har sin egen mappe til konfigurationsfiler, worlds, mods og plugins.

  1. → 1
    UPLOAD EN FIL
    Gå til Filer i menuen → Vælg din storage-zone → Klik på "Upload" knappen → Vælg filen fra din computer.
    💡
    Du kan uploade flere filer på én gang ved at holde Ctrl nede mens du vælger dem.
  2. → 2
    FLYT ELLER SLET EN FIL
    Højreklik på filen → Vælg "Flyt" eller "Slet". Bemærk: Sletning kan ikke fortrydes!
    ⚠
    Sletning er permanent. Der er ingen papirkurv.

// Brugerstyring
MULTI-USER PROFILER

ByteForge understøtter flere brugere med individuelle adgangsniveauer. Giv venner eller familiemedlemmer adgang til specifikke dele af systemet.

  1. → 1
    ADGANGSNIVEAUER
    Admin — Fuld adgang til alt inkl. brugeroprettelse og sletning af servere.
    Bruger — Kan starte/stoppe servere og uploade filer. Kan ikke slette eller ændre konfiguration.
    Gæst — Kan kun se status. Ingen ændringer tilladt.
  2. → 2
    OPRET EN NY BRUGER
    Åbn panelet → Klik på "Brugere" → Klik "+ Ny bruger" → Udfyld brugernavn og adgangskode → Vælg adgangsniveau → Klik "Gem".
    💡
    Opret altid mindst én ekstra admin som backup i tilfælde af at du glemmer din adgangskode.

// Web Hosting
HOST DIN EGEN HJEMMESIDE

ByteForge kan hoste statiske hjemmesider direkte fra PUBLIC storage-zonen. Upload dine HTML/CSS/JS-filer og de er øjeblikkeligt tilgængelige via HTTP.

  1. → 1
    UPLOAD DIN HJEMMESIDE
    Gå til Filer → Public → Upload din index.html fil.
    http://[SERVER-IP]:8080/public/index.html
  2. → 2
    GØR DET TILGÆNGELIGT FRA INTERNET
    Forward port 8080 i din router til serverens lokale IP-adresse. Derefter er siden tilgængeligt på din offentlige IP.
    💡
    Brug DuckDNS eller No-IP for at få et domænenavn – f.eks. minserver.duckdns.org

FAQ
Hvad koster det at drive ByteForge?
ByteForge kører på din egen hardware – der er ingen månedlige abonnementer eller cloud-gebyrer. Du betaler kun for den strøm serveren bruger, typisk 15-30W for en moderne mini-PC. Det svarer til ca. 100-200 kr. om måneden i strøm.
Skal jeg have teknisk erfaring for at bruge det?
ByteForge panelet er designet til at være brugervenligt. De fleste funktioner kræver kun klik i browseren. Terminal-kommandoer er kun nødvendige ved den første opsætning, og guiden her forklarer præcist hvad du skal gøre.
Er mine data sikre?
Ja – fordi alt kører på din egen hardware i dit eget netværk. Dine filer forlader aldrig din server medmindre du aktivt sender dem videre. Med RAID 1 er dine data desuden beskyttet mod diskfejl.
Hvad sker der hvis strømmen går?
Alle services er konfigureret til at starte automatisk når serveren genstarter. Docker-containere, ByteForge panelet, NFS-serveren og Minecraft starter alle op af sig selv via systemd.
Kan jeg tilgå serveren udefra hjemmenet?
Ja – ved at port-forwarde portene i din router (se Port-oversigten ovenfor). Derefter kan du bruge din offentlige IP-adresse til at tilgå ByteForge fra hvor som helst i verden. For ekstra sikkerhed anbefales WireGuard VPN.
Kan jeg tilføje flere apps?
Absolut. Via ByteForge panelet kan du deploye komplette Docker-stacks med presets – Jellyfin, Nextcloud, Grafana, Bitwarden og mange flere, alt med ét klik.
Hvordan kører jeg ByteForge permanent i baggrunden?
Kør terminal-installeren. På Linux opretter install.sh en systemd-service. På macOS opretter den en launchd-service. På Windows opretter install.ps1 en Scheduled Task. Herefter starter ByteForge automatisk ved login eller boot.
Virker ByteForge på Windows?
Ja. Kør install.ps1 fra PowerShell eller brug install.bat. Game servers og app store kræver Docker Desktop for Windows, som installeren kan hjælpe med via winget.
