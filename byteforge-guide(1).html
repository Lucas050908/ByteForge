// Hvad er ByteForge?
EN SERVER
DU EJER

ByteForge er et selvhostet homelab kontrolpanel der kører på din egen computer. Tænk på det som dit eget private cloud — men uden månedlige abonnementer, uden at sende dine data til fremmede servere, og uden begrænsninger.

Det kører på Linux, macOS og Windows med en enkel installer. Du styrer alt fra en browser — game servers, filer, Docker apps, NAS-deling, sikkerhed og meget mere.

Alt er tilgængeligt fra hvilken som helst enhed på dit netværk. Ingen app-downloads, ingen cloud-login. Bare din server, dit panel.

// Installation
INSTALLATION OG OPSTART

ByteForge installeres fra terminalen på Linux, macOS og Windows. Installeren tjekker Python-version, vælger admin-password, opsætter service og håndterer Docker automatisk.

  1. → 1
    DOWNLOAD OG UDPAK
    Klik på "Download ByteForge" knappen. Filen hedder ByteForge.zip. Gem den og udpak den.
    # Terminal (Linux / macOS) unzip ByteForge.zip && cd ByteForge
    💡
    Windows: Højreklik på ZIP-filen → "Udpak alt". Åbn den udpakkede mappe — du skal se install.bat, start.bat og ByteForge-mappen.
  2. → 2
    INSTALLER ELLER QUICK-START
    Fuld installation opsætter ByteForge som en service der starter ved boot. Quick-start kører serveren direkte uden at installere noget.
    # Fuld installation — Linux sudo ./install.sh # Fuld installation — macOS ./install.sh # Fuld installation — Windows PowerShell .\install.ps1 # Quick-start uden installation — Linux ./start.sh # Quick-start uden installation — Windows Dobbeltklik på start.bat
  3. → 3
    ÅBEN PANELET
    Åbn din browser og gå til adressen nedenfor. Ved første login vælger du et admin-password.
    http://127.0.0.1:8080 Brugernavn: ADMIN
    💡
    Kører ByteForge på en anden computer? Brug den computers lokale IP i stedet — f.eks. http://192.168.1.100:8080. Find IP med: ip a (Linux) / ipconfig (Windows).
  4. → 4
    STOP SERVEREN
    Quick-start: tryk CTRL+C i terminalen eller kør stop-kommandoen. Installeret service: brug systemctl.
    # Stop quick-start (Linux) ./start.sh stop # Stop quick-start (Windows) start.bat stop # Stop installeret service (Linux) sudo systemctl stop byteforge
🔴
Docker skal installeres separat. Installeren tilbyder at installere Docker automatisk — sig ja når den spørger. Game servers og app store virker ikke uden Docker.

NAS OG FILDELING

Tilslut NAS-drevet fra alle enheder på dit netværk. Windows bruger Stifinder, Mac bruger Finder, Linux bruger mount.

  1. → 1
    OPSÆT NAS I PANELET

FAQ
Hvad er forskellen på install.sh og start.sh?
install.sh kører én gang og opsætter ByteForge som en permanent service der starter automatisk ved boot (via systemd). Kræver sudo.

start.sh starter bare serveren direkte fra projektmappen — ingen installation, ingen systemd. Perfekt til at teste. Stop med ./start.sh stop.
Hvad koster det at drive ByteForge?
ByteForge kører på din egen hardware — der er ingen abonnementer eller cloud-gebyrer. Du betaler kun for strømmen: typisk 15-30W for en mini-PC, svarende til ca. 100-200 kr. om måneden.
Skal jeg have teknisk erfaring?
Næsten ikke. Den eneste tekniske del er at køre installeren i terminalen én gang. Herefter styres alt via browseren med klik. Guiden her forklarer præcist hvad der skal gøres.
Er mine data sikre?
Ja — fordi alt kører på din egen hardware. Dine filer forlader aldrig din server. ByteForge har desuden rate limiting på login (5 forsøg → 5 minutters lockout) og admin-passwordet gemmes krypteret i en sikker systemfil.
Hvad sker der hvis strømmen går?
Hvis du har brugt installeren: alle services starter automatisk igen. Docker-containere, ByteForge-panelet og NFS-serveren starter alle op af sig selv via systemd/launchd. Bruger du start.sh: du skal starte manuelt igen.
Kan jeg tilgå serveren udefra?
Ja — ved at port-forwarde port 8080 i din router til serverens lokale IP. For ekstra sikkerhed anbefaler vi WireGuard VPN (installeres med ét klik via panelet) — så skal du kun forwarde én port.
Virker ByteForge på Windows?
Ja. Dobbeltklik på start.bat for en hurtig start — den finder Python, åbner browseren og starter serveren automatisk. For permanent installation køres install.ps1 i PowerShell. Game servers kræver Docker Desktop for Windows.
Hvad er den nye fil-manager?
Fil-manageren viser nu dine filer som ikoner ligesom CasaOS — store farvekodet ikoner for billeder, video, kode, arkiver osv. Du kan klikke på filer for preview, højreklikke for omdøb/download/slet, og trække filer ind for upload. Den åbner automatisk i din hjemmemappe.
